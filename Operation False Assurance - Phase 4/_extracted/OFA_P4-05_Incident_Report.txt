1. EXECUTIVE SUMMARY
During Phase 4 of Operation False Assurance (Interactive Control and Long-Lived External Sessions), threat hunting was
conducted across network sensor telemetry within Security Onion to investigate anomalous outbound traffic on non-standard
ports. A search targeting destination port 2222/TCP revealed 124 persistent, recurring connection streams originating from
compromised internal workstation 10.11.28.101 and contacting the external IP address 86.159.48.25 . Detailed NIDS alert
inspection identified consistent Suricata signature hits for ET JA3 Hash - [Abuse.ch] Possible Dridex , exhibiting automated
3-minute periodic beaconing intervals. Zeek SSL and connection logs confirmed that this channel functioned as an interactive,
encrypted command-and-control (C2) session.

Attack Reconstruction
Following initial staging and internal Active Directory reconnaissance within the mytallbeer.com domain, the threat actor
established a long-lived, interactive external session from the compromised host 10.11.28.101 . Rather than relying solely on
standard HTTP/HTTPS ports, the adversary configured an outbound TLS backdoor communicating over TCP port 2222 to the
dedicated external controller at 86.159.48.25 . The malware executed programmed heartbeats approximately every 3 minutes
(e.g., 18:18:00, 18:21:09, 18:24:22, 18:25:29, 18:28:35, 18:31:47, 18:35:02, 18:38:12, 18:41:20), providing persistent command
execution capabilities, task polling, and data transmission.

5. CONTAINMENT, ERADICATION AND RECOVERY
Immediate Actions
Immediately isolate workstation 10.11.28.101 from the network to terminate active C2 sessions with 86.159.48.25 .
Deploy border firewall rules to drop all traffic to/from 86.159.48.25 on all ports.
Terminate malicious processes on 10.11.28.101 holding open sockets to remote port 2222.
Additional Recommendations
Egress Filtering: Implement default-deny egress policies allowing outbound traffic only on approved standard ports (e.g., 80,
443 via proxy).
Endpoint Forensics: Perform memory analysis on 10.11.28.101 to extract the malware payload, configuration files, and
injected DLLs.
Credential Revocation: Invalidate all active tokens and reset passwords for accounts associated with the compromised
endpoint.
System Restoration: Re-image the infected workstation from a trusted baseline before reconnecting to the domain.
6. CONCLUSION
During Phase 4, network telemetry confirmed that compromised host 10.11.28.101 established 124 persistent, encrypted C2
connections to external destination IP 86.159.48.25 over non-standard port 2222/TCP . Suricata NIDS alerts verified Dridex
JA3 beaconing behavior occurring at ~3-minute intervals. Submission of flag CTK{86.159.48.25} was validated as correct on
the CyberEx assessment portal.
7. EVIDENCE LIMITATIONS
Due to TLS encryption on port 2222, decrypted plaintext command strings were not recoverable from the raw packet stream.
Process-level endpoint artifacts are required to confirm the initial binary execution vector on the client.
