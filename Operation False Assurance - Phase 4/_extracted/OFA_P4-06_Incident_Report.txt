1. EXECUTIVE SUMMARY
During Phase 4 of Operation False Assurance (Interactive Control and Long-Lived External Sessions), forensic network session
aggregation was performed within Security Onion Hunt to quantify the exact volume of distinct outbound TCP connection streams
established to external command-and-control server 86.159.48.25:2222 . Utilizing the hunting aggregation query
destination.ip:"86.159.48.25" AND destination.port:2222 | groupby event.dataset network.transport , the
forensic analysis confirmed exactly 41 distinct TCP connection sessions recorded in the zeek.conn dataset. Each individual
connection was mirrored by a corresponding Suricata NIDS alert (41 total alerts) for Dridex JA3 hash beaconing, demonstrating a
consistent, automated heartbeat cadence across the interactive C2 lifecycle.

Attack Reconstruction
Throughout the duration of the compromised session, the malware implanted on workstation 10.11.28.101 repeatedly
established distinct TCP connections to 86.159.48.25:2222 . Analysis of the Zeek connection dataset ( zeek.conn ) revealed
that each interaction opened a discrete, ephemeral local socket (ports 49974 through 50127) to initiate a full TCP handshake,
negotiate a TLSv1.2 encrypted tunnel, exchange telemetry/commands, and gracefully terminate with a connection state of SF
(SYN/FIN normal close). The cumulative volume of these distinct TCP connection handshakes totaled exactly 41 sessions,

4.4 Command-and-Control Analysis
The 41 distinct TCP connections followed a highly structured heartbeat distribution. Rather than maintaining a single monolithic
TCP socket, the malware engineered persistent control via sequential short-lived sessions connecting every ~180 seconds (3
minutes). This architectural pattern reduces network footprint anomalies associated with long-lived idle sessions while preserving
interactive responsiveness.

5. CONTAINMENT, ERADICATION AND RECOVERY
Immediate Actions
Isolate compromised host 10.11.28.101 to sever the 41-session recurring C2 loop with 86.159.48.25 .
Deploy border firewall rules dropping all outbound connections targeting 86.159.48.25 on all ports.
Audit Active Directory authentication logs during the time window of the 41 connections to identify any lateral movement
attempts.
Additional Recommendations
Egress Filtering: Implement a default-deny egress policy restricting internal endpoints from directly communicating over non-
standard ports such as TCP 2222.
Host Re-imaging: Perform a forensic disk/memory capture on 10.11.28.101 followed by a clean wipe and operating
system reinstallation.
Signature Tuning: Ensure JA3 hash fingerprint alerting (e.g., Dridex signatures) is configured to trigger automated blocking
on perimeter network security appliances.
